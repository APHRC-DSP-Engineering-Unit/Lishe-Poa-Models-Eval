③ Manual review: human check against the ground truth

Each reviewer gets batches of 33 random products. For every product, compare each model's output to the ground truth in the six categories, then tick Correct, Wrong or N/A.

How to review

  1. Pick your name in the reviewer sections at the top. Your choice is remembered in this browser.
  2. Generate a batch of 33 random products. They are drawn from your share of the dataset (the 1,500 products are split evenly and at random between Clive, Abigail and Roda), so no two reviewers ever get the same product.
  3. For each product, read the ground truth column, then each model's column, one category at a time: Identity (name, brand, manufacturer, category, country, barcode), Package, Nutrition basis (per 100 g / ml / serving, serving size), Nutrients, Ingredients, and Other label information.
  4. Tick ✓ Correct if the model's values for that category mean the same as the ground truth (ignore capital letters, spacing and harmless wording). Tick ✗ Wrong if any value is wrong, missing or invented. Tick N/A only if there is nothing to compare (both empty). Categories that are empty everywhere are pre-set to N/A.
    Empty ground truth? If the model gives a value the ground truth doesn't have, check the label image if you can. A made-up value is ✗ Wrong. For Other label information, the people typing the ground truth only copied part of the label, so extra text from the model is fine. If the ground truth is empty there, choose N/A.
  5. If the ground truth itself looks wrong (typo, wrong unit, wrong product), tick ⚠ Ground truth looks wrong and add a note. These are listed under Team results.
  6. A product counts as checked once all 18 boxes (6 categories × 3 models) are set. Work is saved automatically to reviews/<your-name>.json.
  7. Share progress by committing your reviews/<name>.json file to git (each reviewer has their own file, so there are no merge conflicts), or have one person run python3 serve.py --lan so everyone reviews on the same server.

The 📊 Snapshot tab compares regex, LLM judge and manual review per category and field. The Pass threshold slider in the tab bar sets one pass mark for all three methods, everywhere on this page.

Tip: keep “Show automated verdicts” off while you review so the regex and LLM-judge results don't influence your decision. The Team results tab compares human verdicts with both automated methods.
